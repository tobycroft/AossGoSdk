# V3 开放接口（Agnes AI / 邮件）

V3 是 AOSSTP8 提供的开放接口，当前包含 Agnes AI 与邮件（SMTP）两类能力。
本模块使用 **V3 凭证信封鉴权**（请求头 `X-Aoss-Ts` / `X-Aoss-Kid` / `X-Aoss-Auth`），
与 V1/V2 的 `?token=` 明文方式完全不同，请勿混用。

## 包导入

```go
import AossGoSdk "github.com/tobycroft/AossGoSdk"
```

> `secret` 由 AOSSTP8 后台「项目管理 v3」页签发（64 位十六进制），请通过配置注入，勿硬编码。

## 创建客户端

```go
ai := AossGoSdk.NewV3Ai(secret, "")
// endpoint 传空字符串时复用 SDK 公用地址（conf.go 的 baseUrl）；也可显式传入自定义地址
```

## 结构体

```go
type V3Ai struct {
    Secret  string // 服务端签发的凭证，同时作为信封密钥
    BaseUrl string // AOSSTP8 站点根地址
}
```

每个方法返回 `(any, error)`：`error != nil` 表示请求失败或 `code != 0`（错误信息为 `echo`）；
成功时 `any` 为上游原样响应结构（通常是 `map[string]any`，可按需要断言）。

## 对话补全 ChatCompletions

```go
func (self *V3Ai) ChatCompletions(messages any, options map[string]any) (any, error)
```

```go
data, err := ai.ChatCompletions(
    []map[string]any{{"role": "user", "content": "你好"}},
    map[string]any{"model": "agnes-3.0-flash", "max_tokens": 1024},
)
```

`options` 支持：`model, temperature, max_tokens, top_p, stream, tools, tool_choice, chat_template_kwargs`。

**开启推理（OpenAI 格式）**：

```go
data, err := ai.ChatCompletions(messages, map[string]any{
    "chat_template_kwargs": map[string]any{"enable_thinking": true},
})
```

## Responses

```go
func (self *V3Ai) Responses(input any, options map[string]any) (any, error)
```

```go
data, err := ai.Responses("总结这个任务并列出需要的工具", map[string]any{
    "max_output_tokens": 1024,
})
```

`options` 支持：`model, instructions, temperature, max_output_tokens, top_p, stream, chat_template_kwargs`（推理开关同 ChatCompletions）。

## Messages（Anthropic 兼容）

```go
func (self *V3Ai) Messages(messages any, options map[string]any) (any, error)
```

```go
data, err := ai.Messages(messages, map[string]any{"max_tokens": 2048})
```

`options` 支持：`model, system, temperature, max_tokens, top_p, stream, thinking, chat_template_kwargs`。

**开启推理（Anthropic 格式，注意与 OpenAI 格式不同）**：

```go
data, err := ai.Messages(messages, map[string]any{
    "thinking": map[string]any{"type": "enabled", "budget_tokens": 2048},
})
```

## 邮件（Mail）

```go
mail := AossGoSdk.NewV3Mail(secret, "")
// endpoint 传空字符串时复用 SDK 公用地址（conf.go 的 baseUrl）

data, err := mail.SendCaptcha("alice@example.com", "login_code", "882913", nil)
```

前置条件：项目已在 AOSSTP8 后台「邮件管理 → 邮件授权」分配至少一台启用中的 SMTP 服务器；
验证码/营销类型还须在「邮件管理 → 邮件模板」配置并启用对应模板。三类内容区别：

| 类型 | 后台维护 | 调用方提供 |
|------|----------|------------|
| 验证码 | 主题、正文模板（含 `{code}`） | `to`、`template`、`code`（<=16 位） |
| 营销 | 主题、正文模板（含 `{变量名}`） | `to`、`template`、`vars` |
| 自定义 | 无 | `to`、`subject`、`body` |

每个方法返回 `(any, error)`：`error != nil` 表示请求失败或 `code != 0`（错误信息为 `echo`）；
成功时 `any` 通常为 `map[string]any`，含 `message_id` 与 `type`。

### SendCaptcha 验证码邮件

```go
func (self *V3Mail) SendCaptcha(to, template, code string, options map[string]any) (any, error)
```

```go
data, err := mail.SendCaptcha("alice@example.com", "login_code", "882913",
    map[string]any{"cc": "audit@example.com"})
```

`options` 支持：`cc, alt_body, from_addr, from_name, server_id`。

### SendMarketing 营销邮件

```go
func (self *V3Mail) SendMarketing(to, template string, vars map[string]any, options map[string]any) (any, error)
```

```go
data, err := mail.SendMarketing("alice@example.com,bob@example.com", "promo_spring",
    map[string]any{"link": "https://example.com/promo", "name": "张三"}, nil)
```

`vars` 的键对应后台模板里的 `{变量名}`，最多 50 项、单值最长 1000 字符，只接受标量。
有占位符未提供值时会返回 error 且不发信。`options` 同 `SendCaptcha`。

### SendCustom 自定义邮件

```go
func (self *V3Mail) SendCustom(to, subject, body string, options map[string]any) (any, error)
```

```go
data, err := mail.SendCustom("alice@example.com", "系统通知", "<h3>您好</h3>",
    map[string]any{"is_html": 1})
```

`options` 支持：`cc, alt_body, is_html, from_addr, from_name, server_id`。
服务端另保留兼容入口 `/v3/mail/send/custom` 的旧路径 `/v3/mail/send/index`，新代码建议直接使用 `SendCustom`。

## 鉴权说明

V3 客户端每次请求都会：

1. 取当前秒级时间戳 `ts`；
2. `kid = V3Kid(secret)`；
3. `auth = V3Seal(secret, ts)`（AES-256-GCM，随机 IV）；
4. 以请求头方式发送，绝不使用 `?token=` 或表单中的明文凭证。

派生与加密逻辑见 `v3_envelope.go`，已通过 PHP 服务端参考向量双向验证互通。
